# Audio assets

All `.wav` files in this directory are **procedurally generated** (sine
waves + envelopes + filtered noise) by the script committed alongside
the Phase 5 PR. They have **no upstream author** and are released into
the **public domain** (CC0). Drop in higher-quality samples as you wish;
the engine code only assumes the file paths and is sample-rate
agnostic.

| File              | Trigger                       | Length |
|-------------------|-------------------------------|--------|
| `axe_chop.wav`    | NPC finishes chopping a tree  | ~0.18s |
| `build_hammer.wav`| Building stage advances       | ~0.32s |
| `birth_chime.wav` | New child is born             | ~0.55s |
